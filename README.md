# 照片权重排版工具

一个依据《PRD：照片权重排版工具 v0.4》实现的本地 Web 原型。项目不依赖后端，原图只在当前浏览器页面中处理。

## 已实现

- 批量拖拽/选择照片，缩略图列表，删除和替换
- 左侧照片列表默认保留原有格式；四宫格按钮可切换缩略图模式，小图下部可直接修改权重，再点一次恢复列表；支持全选后批量设置权重
- 单张权重设置，以及多选后的批量权重设置
- A4、B5、TN、M5、A7、A8、相纸等常用尺寸，支持自定义尺寸和横竖方向
- 系统建议页数或手动指定页数
- 中间画布下方显示带页码的页面缩略图，右侧单独显示候选排版方案的大图预览及页数选项；纸张尺寸区域可独立收起
- 基于权重平衡的多页分配与自适应矩形分区排版：多种照片顺序、分组、横/竖切分比例和分区树结构共享同一候选池
- 保持原比例 / 允许裁切两种模式
- 自动比较横放与竖放，选择更贴合版面的 90° 旋转方向
- 自动布局会优先匹配原图比例；允许裁切时至少保留约 70% 原图面积
- 布局引擎使用权重目标面积、面积排序惩罚和高权重相对面积下限，权重是软约束而不是机械等比切分
- 每个页数会生成多个候选树结构，并用实际覆盖率、权重排序、目标面积偏差、裁切损失、最小尺寸和视觉平衡综合评分
- 候选布局会再执行相邻矩形边界移动和照片区域交换的局部搜索，尝试扩大可利用区域；所有调整都通过无重叠、页边界和最小短边校验
- 多页推荐会比较不同页数的利用率、裁剪损失、最小短边、比例误差、权重违例和页数成本
- 可设置最小照片短边、独立照片间距、可选白边宽度和裁切辅助线
- 支持 Weight Priority、Balanced（默认）和 Space Priority 三种排版优化模式；切换模式会重新生成候选布局
- 最小短边现在是硬约束：候选生成、边界优化和导出前验证都会检查物理毫米尺寸；当前页数无法满足时会提示增加页数
- 三种模式共享同一候选布局池；Weight Priority 先比较权重排序/目标面积质量，再在质量接近的候选中比较覆盖率；Space Priority 先过滤硬约束和权重质量底线，再按真实照片覆盖率选择方案
- 空间指标区分“实际照片覆盖率”和“矩形占用率”，contain 留下的图片内空白、照片间距和未覆盖区域不会再被误报为 100%
- 开启布局调试信息后，可查看每张照片的权重、面积、面积/权重排名、排序违例、最小短边、裁切保留率和每页空白面积
- 自动排版与手动编辑分离：自动排版只负责生成初始页面；进入手动编辑后，照片是独立对象，可自由移动、重叠、缩放、旋转、复制、删除和调整图层顺序
- 手动编辑使用页面毫米坐标，支持四角/边缘缩放、锁定显示框比例、统一页面背景色、撤销/重做和恢复最近一次自动排版
- 裁切编辑改为非破坏式交互裁切框，原始图片不被修改；预览、PNG 和 PDF 共用背景、图层顺序、坐标和裁切数据

自动布局采用独立的 `layout-engine.js`：先尝试多个页数，再对每页生成多个横切/竖切候选；候选方案按照片数量完整性、最小尺寸、裁剪损失、原图比例、空间利用率、权重目标面积和页面权重平衡进行多目标评分，最后进行边界局部搜索。
- 画布内拖动、右下角缩放、页面缩略图切换
- 单张照片手动裁切
- 可保存当前页 PNG，或将全部页面的 PNG 打包为一个 ZIP 下载；全部页面也可通过浏览器打印对话框导出 PDF
- 打印/PDF 直接使用已绘制完成的页面 Canvas；打印内容不会在对话框仍打开时被定时清空
- 关闭页面前的未导出提示

## 使用

直接打开 `index.html` 即可。也可以在当前目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 5173
```

然后访问 `http://localhost:5173/`。

## 算法测试

使用项目内置 Node 运行时执行纯几何测试：

```powershell
node tests/layout-engine.test.js
node tests/manual-editor.test.js
node tests/page-layout.test.js
node tests/print-export.test.js
node tests/png-zip.test.js
node tests/png-export.test.js
```

测试覆盖高权重照片、空白回收、横竖图混排、多页 A4、间距开关、权重变更、三种优先级模式、共享候选池、最小短边硬约束和 contain 的真实空白统计，并检查所有照片保留、页边界和矩形不重叠；固定验收数据还会输出 Coverage、Target Area Error、Crop Loss、Minimum Short Side Violations 和 Weight Ranking Violations。`manual-editor.test.js` 还会检查自由编辑层、统一背景、图层顺序、缩放控制点、交互裁切框和撤销/重做结构。

## 当前原型边界

自动布局和裁切在浏览器端完成，自动人脸识别、云端保存和跨页拖拽尚未纳入本次 P0 实现。PDF 导出使用浏览器打印流程，可在打印对话框中选择“另存为 PDF”。
